# Electroidea Web V4

Sitio estático listo para revisión y publicación.

## Incluye
- Electricidad y emergencias eléctricas 24/7
- Cámaras de seguridad
- Automatización, instalación y reparación de motores de portones
- Chapas eléctricas
- Citófonos, intercomunicadores y videoporteros
- Reparación de cabezas móviles / iluminación LED profesional
- Reparación de bolas de espejos
- Pisos flotantes y vinílicos
- Mantenciones y reparaciones generales
- Formulario que prepara la cotización en WhatsApp
- Diseño responsive para celular
- SEO básico, robots.txt y sitemap.xml

## Antes de publicar definitivamente
Reemplazar/añadir fotos reales al portafolio cuando estén disponibles y verificar que teléfono, cobertura y certificación mostrados sean los datos que Electroidea desea publicar.
